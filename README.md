# Aurynix Nexus

Aurynix Nexus is an AI-powered business assistant designed to help teams work smarter by combining conversational AI, enterprise knowledge, and business tools into a single intelligent workspace.

## Features

- AI Chat
- Long-Term Memory
- Retrieval-Augmented Generation (RAG)
- PDF Knowledge Base
- Tool Calling
- Multi-Agent Workflows
- Gmail Integration
- Calendar Integration
- Web Search
- Human Handoff

## Tech Stack

- FastAPI
- LangGraph
- OpenAI
- PostgreSQL
- Redis
- Qdrant
- Docker
